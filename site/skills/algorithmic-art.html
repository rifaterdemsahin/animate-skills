Algorithmic Art

Anthropic's skill for generative art: the agent writes an algorithmic philosophy, then expresses it as a seeded p5.js sketch with flow fields, particles and noise, plus parameter controls.

💬 2. Prompt it (execution)

Name the skill in your prompt so Claude loads its SKILL.md before acting.

prompt
Use the algorithmic-art skill. Create a flow-field piece inspired by wind over water, seeded, with sliders for particle count and noise scale.

🧠 What the agent does

  1. Agent writes a short algorithmic philosophy (.md).
  2. Implements it as a p5.js sketch with randomSeed/noiseSeed.
  3. Adds UI controls for parameters.
  4. Returns a self-contained HTML artifact.

🧪 Core pattern (artifact)

code
function draw() {
  for (const p of particles) {
    const a = noise(p.x * s, p.y * s) * TAU * 2;
    p.add(cos(a), sin(a)); point(p.x, p.y);
  }
}

📄 CLAUDE.md snippet

Paste into your project's CLAUDE.md so every session knows when to use this skill.

CLAUDE.md
## Animation skill: Algorithmic Art
- For generative backgrounds, art pieces, seeded variations you can reproduce, load the `algorithmic-art` skill before writing code.
- Runtime: p5.js. Expected artifact: Interactive generative-art HTML.
- Animate transform and opacity only; always respect prefers-reduced-motion.
- Put source in `animations/algorithmic-art/`, write rendered output to `out/` (git-ignored).
- After rendering, report the artifact path and how to preview it.

🪝 Hook: check every edit

Add to .claude/settings.json. After each Write/Edit of a .js file, Claude Code runs the check and the output comes back to the agent.

.claude/settings.json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write|Edit",
        "hooks": [
          {
            "type": "command",
            "command": "f=$(jq -r '.tool_input.file_path // empty'); case \"$f\" in *.js) grep -q \"randomSeed\" \"$f\" || echo \"⚠️ sketch is not seeded\" >&2 ;; esac; exit 0"
          }
        ]
      }
    ]
  }
}
