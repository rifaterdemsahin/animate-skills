🎬 Video skill

Remotion

Teaches the agent to build videos as React components: compositions, sequences, useCurrentFrame(), interpolate() and spring(). Reference files cover Three.js/React Three Fiber scenes and Lottie embedding.

⚙️ RuntimeReact + Remotion

🏷️ Sourceremotion-dev/skills (official) and community forks
🎯 Use it forProgrammatic, data-driven or templated video: product explainers, social clips, animated charts, captions.

⚡ 1. Install (database)

Pull the skill from the registry into .claude/skills/ so the agent can discover it.

bash
npx skills add remotion-dev/skills

💬 2. Prompt it (execution)

Name the skill in your prompt so Claude loads its SKILL.md before acting.

prompt
Use the remotion skill. Create a 10-second 1080x1080 composition that animates our three Q3 metrics in with spring() and renders to out/q3.mp4.

🧠 What the agent does

  1. Agent loads SKILL.md and its rule files (timing, sequencing, assets).
  2. Scaffolds a Remotion project and writes a Composition in src/.
  3. Previews in Remotion Studio (npx remotion studio).
  4. Renders with npx remotion render to an MP4 artifact.

🧪 Core pattern (artifact)

code
const frame = useCurrentFrame();
const {fps} = useVideoConfig();
const scale = spring({frame, fps, config: {damping: 12}});
return <div style={{transform: `scale(${scale})`}}>Q3</div>;

📄 CLAUDE.md snippet

Paste into your project's CLAUDE.md so every session knows when to use this skill.

CLAUDE.md
## Animation skill: Remotion
- For programmatic, data-driven or templated video: product explainers, social clips, animated charts, captions, load the `remotion` skill before writing code.
- Runtime: React + Remotion. Expected artifact: MP4 / WebM video.
- Animate transform and opacity only; always respect prefers-reduced-motion.
- Put source in `animations/remotion/`, write rendered output to `out/` (git-ignored).
- After rendering, report the artifact path and how to preview it.

🪝 Hook: check every edit

Add to .claude/settings.json. After each Write/Edit of a .tsx file, Claude Code runs the check and the output comes back to the agent.

.claude/settings.json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write|Edit",
        "hooks": [
          {
            "type": "command",
            "command": "f=$(jq -r '.tool_input.file_path // empty'); case \"$f\" in *.tsx) npx tsc --noEmit ;; esac; exit 0"
          }
        ]
      }
    ]
  }
}
