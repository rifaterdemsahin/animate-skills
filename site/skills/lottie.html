🫧 Web skill

Lottie

Guides the agent through loading, controlling and segment-playing After Effects Lottie files, plus wiring them to hover, scroll or state changes.

🔎 View on skills.sh 📦 Source
⚙️ Runtimelottie-web / dotLottie
🎁 ArtifactVector animation JSON embedded in a page or video
🏷️ Sourceiart-ai/web-animation-skills (lottie skill) and Remotion Lottie rules
🎯 Use it forDesigner-made icon animations, onboarding illustrations, loaders exported from After Effects.

⚡ 1. Install (database)

Pull the skill from the registry into .claude/skills/ so the agent can discover it.

bash
npx skills add iart-ai/web-animation-skills

💬 2. Prompt it (execution)

Name the skill in your prompt so Claude loads its SKILL.md before acting.

prompt
Use the lottie skill. Embed success.json, play frames 0-60 on submit and loop 60-90 while the request is pending.

🧠 What the agent does

  1. Agent identifies the Lottie asset and its markers/segments.
  2. Writes lottie.loadAnimation() with renderer, loop and autoplay set.
  3. Binds playSegments() to UI events.
  4. Produces an HTML artifact or a Remotion <Lottie> layer.

🧪 Core pattern (artifact)

code
const anim = lottie.loadAnimation({container: el, path: 'success.json', autoplay: false});
form.onsubmit = () => anim.playSegments([0, 60], true);

📄 CLAUDE.md snippet

Paste into your project's CLAUDE.md so every session knows when to use this skill.

CLAUDE.md
## Animation skill: Lottie
- For designer-made icon animations, onboarding illustrations, loaders exported from after effects, load the `lottie` skill before writing code.
- Runtime: lottie-web / dotLottie. Expected artifact: Vector animation JSON embedded in a page or video.
- Animate transform and opacity only; always respect prefers-reduced-motion.
- Put source in `animations/lottie/`, write rendered output to `out/` (git-ignored).
- After rendering, report the artifact path and how to preview it.

🪝 Hook: check every edit

Add to .claude/settings.json. After each Write/Edit of a .json file, Claude Code runs the check and the output comes back to the agent.

.claude/settings.json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write|Edit",
        "hooks": [
          {
            "type": "command",
            "command": "f=$(jq -r '.tool_input.file_path // empty'); case \"$f\" in *.json) python3 -m json.tool \"$f\" >/dev/null ;; esac; exit 0"
          }
        ]
      }
    ]
  }
}
