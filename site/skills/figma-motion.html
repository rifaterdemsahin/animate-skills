Figma Motion (MCP)

Reads motion and prototype transitions out of a Figma file so the agent can reproduce them in code, and can export frames as video.

🔎 View on skills.sh 📦 Source
⚙️ RuntimeFigma MCP server (get_motion_context, export_video)
🎁 ArtifactMotion specs and exported video from Figma
🏷️ SourceFigma official MCP server
🎯 Use it forDesigners animate in Figma and engineers need matching CSS/GSAP timings.

⚡ 1. Install (database)

Pull the skill from the registry into .claude/skills/ so the agent can discover it.

bash
Connect the Figma connector in Claude, then load /figma-design-to-code

💬 2. Prompt it (execution)

Name the skill in your prompt so Claude loads its SKILL.md before acting.

prompt
Read the motion context for this Figma frame and reproduce the transition in CSS with the same durations and easing.

🧠 What the agent does

  1. Agent creates a Figma session for the file.
  2. Calls get_motion_context on the frame.
  3. Maps easing/duration to CSS or GSAP.
  4. Returns code plus an optional exported video.

🧪 Core pattern (artifact)

code
// from get_motion_context: { duration: 300, easing: 'ease-out', type: 'smart-animate' }
.panel { transition: transform 300ms ease-out; }

📄 CLAUDE.md snippet

Paste into your project's CLAUDE.md so every session knows when to use this skill.

CLAUDE.md
## Animation skill: Figma Motion (MCP)
- For designers animate in figma and engineers need matching css/gsap timings, load the `figma-motion` skill before writing code.
- Runtime: Figma MCP server (get_motion_context, export_video). Expected artifact: Motion specs and exported video from Figma.
- Animate transform and opacity only; always respect prefers-reduced-motion.
- Put source in `animations/figma-motion/`, write rendered output to `out/` (git-ignored).
- After rendering, report the artifact path and how to preview it.

🪝 Hook: check every edit

Add to .claude/settings.json. After each Write/Edit of a .css file, Claude Code runs the check and the output comes back to the agent.

.claude/settings.json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write|Edit",
        "hooks": [
          {
            "type": "command",
            "command": "f=$(jq -r '.tool_input.file_path // empty'); case \"$f\" in *.css) grep -nE \"transition|animation\" \"$f\" ;; esac; exit 0"
          }
        ]
      }
    ]
  }
}
