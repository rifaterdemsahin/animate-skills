CLAUDE.md
## Animation skill: Three.js / WebGL
- For 3d product spins, particle hero sections, shader backgrounds, load the `threejs-webgl` skill before writing code.
- Runtime: Three.js, React Three Fiber, shaders. Expected artifact: Interactive 3D scene.
- Animate transform and opacity only; always respect prefers-reduced-motion.
- Put source in `animations/threejs-webgl/`, write rendered output to `out/` (git-ignored).
- After rendering, report the artifact path and how to preview it.

🪝 Hook: check every edit

Add to .claude/settings.json. After each Write/Edit of a .js file, Claude Code runs the check and the output comes back to the agent.

.claude/settings.json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write|Edit",
        "hooks": [
          {
            "type": "command",
            "command": "f=$(jq -r '.tool_input.file_path // empty'); case \"$f\" in *.js) npx --yes prettier --check \"$f\" ;; esac; exit 0"
          }
        ]
      }
    ]
  }
}
