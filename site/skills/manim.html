🧠 What the agent does

  1. Agent writes a Python file with a Scene subclass and construct().
  2. Uses self.play(Create(...), Transform(...)) for each beat.
  3. Runs manim -pqh scene.py PythagorasScene.
  4. Collects the MP4 from media/videos as the artifact.

🧪 Core pattern (artifact)

code
class Pythagoras(Scene):
    def construct(self):
        eq = MathTex('a^2 + b^2 = c^2')
        self.play(Write(eq))
        self.play(eq.animate.scale(1.5).set_color(YELLOW))

CLAUDE.md
## Animation skill: Manim
- For equations, proofs, geometry, algorithm walk-throughs and teaching videos, load the `manim` skill before writing code.
- Runtime: Python + Manim Community Edition. Expected artifact: MP4 / GIF explainer.
- Animate transform and opacity only; always respect prefers-reduced-motion.
- Put source in `animations/manim/`, write rendered output to `out/` (git-ignored).
- After rendering, report the artifact path and how to preview it.

🪝 Hook: check every edit

Add to .claude/settings.json. After each Write/Edit of a .py file, Claude Code runs the check and the output comes back to the agent.

.claude/settings.json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write|Edit",
        "hooks": [
          {
            "type": "command",
            "command": "f=$(jq -r '.tool_input.file_path // empty'); case \"$f\" in *.py) manim -ql --dry_run \"$f\" ;; esac; exit 0"
          }
        ]
      }
    ]
  }
}
