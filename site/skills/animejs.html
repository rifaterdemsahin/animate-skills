🧠 What the agent does

  1. Agent creates the DOM/SVG targets.
  2. Writes animate()/timeline calls with stagger and easing.
  3. Adds reduced-motion fallback.
  4. Ships a single HTML artifact.

CLAUDE.md
## Animation skill: Anime.js
- For small pages where gsap is overkill; svg stroke drawing; grid stagger effects, load the `animejs` skill before writing code.
- Runtime: Anime.js. Expected artifact: Animated web page / SVG.
- Animate transform and opacity only; always respect prefers-reduced-motion.
- Put source in `animations/animejs/`, write rendered output to `out/` (git-ignored).
- After rendering, report the artifact path and how to preview it.

🪝 Hook: check every edit

Add to .claude/settings.json. After each Write/Edit of a .js file, Claude Code runs the check and the output comes back to the agent.

.claude/settings.json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write|Edit",
        "hooks": [
          {
            "type": "command",
            "command": "f=$(jq -r '.tool_input.file_path // empty'); case \"$f\" in *.js) npx --yes prettier --check \"$f\" ;; esac; exit 0"
          }
        ]
      }
    ]
  }
}
