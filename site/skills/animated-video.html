⚡ 1. Install (database)

Pull the skill from the registry into .claude/skills/ so the agent can discover it.

bash
npx skills add bluzir/claude-code-design -s animated-video

💬 2. Prompt it (execution)

Name the skill in your prompt so Claude loads its SKILL.md before acting.

prompt
Use the animated-video skill. Storyboard a 15s feature announcement in 4 scenes, then build and export it.

🧠 What the agent does

  1. Agent writes a storyboard with scene durations.
  2. Builds each scene with consistent type and color tokens.
  3. Adds transitions between scenes.
  4. Exports the video artifact.

▶️ Run it again

Source: remotion-video/src/Storyboard.tsx · installed skill: .claude/skills/animated-video

bash
cd remotion-video && npx remotion render Storyboard out/storyboard.mp4

📄 CLAUDE.md snippet

Paste into your project's CLAUDE.md so every session knows when to use this skill.

CLAUDE.md
## Animation skill: Animated Video (design kit)
- For promo loops and feature announcements where the storyboard matters more than code, load the `animated-video` skill before writing code.
- Runtime: HTML/CSS scenes captured to video. Expected artifact: Short animated video.
- Animate transform and opacity only; always respect prefers-reduced-motion.
- Put source in `animations/animated-video/`, write rendered output to `out/` (git-ignored).
- After rendering, report the artifact path and how to preview it.

🪝 Hook: check every edit

Add to .claude/settings.json. After each Write/Edit of a .html file, Claude Code runs the check and the output comes back to the agent.

.claude/settings.json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write|Edit",
        "hooks": [
          {
            "type": "command",
            "command": "f=$(jq -r '.tool_input.file_path // empty'); case \"$f\" in *.html) npx --yes prettier --check \"$f\" ;; esac; exit 0"
          }
        ]
      }
    ]
  }
}
